# 2026-11-06 主题、图表响应与状态栏

本轮根据候选版反馈，缩短主题反馈，避免 Mermaid 在源码未变时重复生成预览，整理底部状态栏并补齐版本标识。文稿保存、撤销、恢复和导出语义保持。

## 交互变化

- 主题表面颜色过渡由 280ms 缩短到 100ms。正文标题、代码等元素一起更新颜色，不再逐个等待颜色动画；图表替换不再附加 220ms 淡入。
- Mermaid 编辑框没有改动源码、主题和字体时，失焦、点击预览或按 Escape 都立即恢复已解码图像，不新增撤销内容。
- 每个图表保留当前源码和字体的两个主题预览；切回已经生成过的主题直接复用。源码或字体变化后清除旧的主题预览，销毁视图时释放引用。
- 相同图表的在途请求合并；没有使用者的旧请求在进入 Mermaid 串行队列前退出，完成较晚的旧结果不能覆盖新图。开始布局前让出一帧给界面；窗口隐藏或暂停帧时有后备路径。
- 新图尚未就绪时保留旧预览，编辑与主题按钮仍可操作。新图完成解码后一次替换，主题变化继续保留图表高度和滚动位置。
- 底部按保存／草稿保护、统计、模式／路径及外观操作分组。新文稿仅显示一次“未保存”，完整文件路径仍可通过悬停查看；正常保存后不重复显示健康的草稿保护状态，保护失败和保存暂停仍给出手动保存指引。
- 状态栏常驻显示由 `package.json` 提供的版本，悬停或键盘聚焦可查看现有构建标识。较窄窗口收起次要统计和操作文字，保留图标、缩放、版本及关键保存反馈。

## 实际测量

在同一个 Windows Chromium 156 浏览器会话中，使用真实 Milkdown／Mermaid 和完整 MiSans 字体，对比本轮修改前的提交 `2727b891b9a4` 与修改后的源码。原生 IPC 为模拟；数据是该夹具的页面内测量，不是安装版或所有图表的性能保证。

| 场景                   | 修改前                             | 修改后                                     |
| ---------------------- | ---------------------------------- | ------------------------------------------ |
| 未改源码的五次失焦预览 | 每次 861–1164ms，5 次 Mermaid 生成 | 每次 0.6–1.2ms，0 次生成                   |
| 深／浅四次顺序切换     | 每次约 1060–1109ms，4 次生成       | 首次约 1026ms，随后 0–0.1ms，合计 1 次生成 |
| 深／浅四次快速切换     | 约 1050ms                          | 约 0.1ms，0 次生成                         |

首次新主题和真正修改过的图表仍需要生成和解码，本机夹具约为 1 秒级。分段测量中 Mermaid 本身约 36ms，完整预览包装及解码合计约 857ms。对同一完整字体 SVG 比较 Base64、百分号编码和 Blob URL，没有稳定的时间收益；本轮保留原有 data URL、严格 Mermaid 渲染和被动图片展示方式。

共享预览字符串缓存最多 4 项，并按保守的 UTF-16 估算限制到 96MiB；这不是整个进程的内存上限。缓存只用于隔离的 SVG 图片。HTML／PDF 导出仍独立渲染每张图表，避免内联 SVG 的 Mermaid 标识重复；字体与离线能力不变。

## 验证范围

前端质量门禁通过，包括 ESLint、格式、配置同步、两套 TypeScript 与覆盖率：52 个测试文件、604 项测试通过，行覆盖率 59.74%，原有门槛未变。

完整浏览器回归 189 项通过，使用真实 React／Milkdown／Mermaid／CSS／字体，原生 IPC 为模拟。新增检查覆盖未改源码失焦、连续切换主题、旧渲染完成后的竞争、编辑期间切换主题，以及九种窗口尺寸下的长路径、大统计值、保存暂停、草稿保护失败、版本可见性和操作命中。

构建来源、最终包哈希与 CI 结果以候选交付清单和 PR 为准。本轮不将浏览器回归计作 WebView2 原生验收；安装、升级／回滚、中文输入法、DPI、真实剪贴板、原生 PDF 和 Windows 10 仍见[候选验收清单](ops/candidate-0.2.6.md)。
