# UI / UX 优化记录（2026-11-19）

本轮围绕开始写作、编辑、查找、保存和恢复内容，简化已有界面与操作。保留现有字体、青绿色主题和产品结构，没有增加依赖、修改版本号或改变文件保存与恢复的数据格式。

当前工作分支为 `dev/0.2.7`，应用版本仍为 `0.2.6`。本轮改动尚未公开发布；验证结果和新构建的安装包身份在下文记录，不沿用旧安装包的结论。

## 操作与界面变化

| 场景           | 优化后的行为                                                                                     |
| -------------- | ------------------------------------------------------------------------------------------------ |
| 开始写作       | 欢迎页、新建按钮、标签栏加号和 Ctrl+N 直接新建空白文档并进入输入；不再先选择模板。               |
| 查看示例       | 欢迎页和「更多」中的「打开示例文档」保留 Markdown 示例，文件名与空白文档明确区分。               |
| 文件操作       | 新建、打开、保存保留在主工具栏；另存为、HTML 导出、打印／保存 PDF 和示例集中到「更多」。         |
| 编辑模式       | 「源码／渲染」改为「Markdown 原文／正文」，切换和返回入口使用相同名称。                          |
| 查找替换       | 「替换」入口直接可见；反复按 Ctrl+F 保留关键词并聚焦输入框；结果只说明实际替换或无法替换的内容。 |
| 排版设置       | 缩小面板，保留正文宽度、字体选择和直观字样；删除重复用途说明与字体技术介绍，设置仍自动保存。     |
| 最近打开       | 文件列表优先显示，并显示目录以区分同名文件；启动设置改为「启动时打开上次的文档」。               |
| 启动提醒       | 文件重新打开失败时不显示常驻横幅；失败记录保留，可在「最近打开」中选择「重新打开失败的文档」。   |
| 未保存内容     | 区分「未保存」「可恢复」和「备份失败」；关闭文档时使用「保存并关闭／不保存／继续编辑」。         |
| 导出和图片     | HTML 导出直接进入保存位置选择；图片插入成功后不保留提示条，进行中、部分失败和错误仍明确显示。    |
| 预览缩放       | 图片和图表预览的 Ctrl+滚轮每次调整 1%，例如 63% → 64%；加减按钮和键盘加减保留 1.25 倍快速缩放。  |
| 空白和窄窗口   | 欢迎页隐藏空标签栏；慢速启动文档时保留等高位置，防止编辑区跳动；窄窗口的查找面板放到底部。       |
| 错误与辅助操作 | 错误页折叠技术详情；图表、快捷键和恢复内容的提示使用可理解的文字，保留失败处理和键盘入口。       |

## 保留的安全与可访问性边界

- 文档、图片和导出文件的路径、类型、容量及并发校验保留。
- 取消保存不宣布成功；磁盘冲突、恢复失败和未保存的改动仍有明确反馈。
- 文档重开失败不清除失败记录或恢复副本；保存的文档列表本身读写失败时仍显示提示。
- 丢弃更改和永久删除恢复副本仍有风险说明；恢复副本在本机保留 7 天、包含文字与图片且未加密的说明保留。
- 对话框焦点、退出时 inert、键盘菜单、输入法防误触、减弱动态效果和窄窗口操作目标继续由回归检查覆盖。
