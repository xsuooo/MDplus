# MDPlus v0.2.4

> 历史记录：本 Release、标签及安装包已于 2026-10-30 撤下。累计代码保留并继续修复，尚未重新发布；下文只记录旧构建，不适用于当前修复版。

> 发布日期：2026-10-30 · 标签：`v0.2.4` · 对比：`v0.2.3...v0.2.4`

## 概述

本次发布加入功能键快捷入口与源码模式撤销/重做历史，修复保存/切换视图时编辑内容被异步覆盖、图片迁移跨标签回写、Mermaid 清空后无法提交等问题，并完成一轮依赖安全修复。

## 改进

- 增加功能键快捷入口，并保留源码模式的撤销/重做历史。

## 修正

- 保存、关闭或切换视图时保留最新编辑内容，防止异步保存和外部重载覆盖后续输入。
- 图片迁移保存完成时依据当前标签和视图同步源码，避免跨标签回写或残留旧占位符。
- Mermaid 清空源码后可正常预览、失焦或按 Escape 提交，并支持撤销恢复。

## 安全依赖

- 更新 DOMPurify、ProseMirror、Vue 等受影响依赖，以及 Mermaid、Vite、Vitest 安全版本。
- KaTeX 固定为 0.18.2，并通过单项 override 统一旧数学依赖链；保留信任校验和公式兼容回归测试。
- 2026-10-29 的生产及全量 `npm audit` 均为 0 告警；这不代表不存在未知漏洞或兼容性风险。

## 验收

- 已在四个独立 Windows 11 x64 沙盒中完成 MSI、NSIS 首次安装，以及各自从 0.2.3 升级到 0.2.4 的验收。
- 安装后的实际版本、文档保存重开、升级数据与设置保留、快捷方式、测试环境中的文件关联均通过。
- 仓库内验证：`npm run typecheck`、`npm test`、`npm run build`、`cargo test`、`cargo clippy` 均通过（日志见发布记录）。

## 已知限制

- 安装包**未签名**（本项目未配置代码签名证书）；Windows SmartScreen 会提示未知发布者，选择“更多信息 → 仍要运行”即可。
- NSIS 安装包请先下载或复制到本地磁盘再运行；从只读共享路径启动存在已观察到的限制。
- 验收未覆盖：跨安装器迁移、降级、卸载、ARM64、非管理员令牌、已有默认应用覆盖、全部输入法/快捷键组合。

## 安装

> 安装包已附在下方 Assets（MSI + NSIS，**未签名**）。下载到**本地磁盘**再运行；Windows 会提示“未知发布者”，选择“更多信息 → 仍要运行”即可。

1. 下载 `MDPlus_0.2.4_x64-setup.exe`（NSIS）或 `MDPlus_0.2.4_x64_zh-CN.msi`（MSI）到**本地磁盘**再运行（只读共享路径存在已知限制）。
2. 升级安装可保留 0.2.3 的文档与设置；卸载/降级不在本次验收范围内。
3. 回退方式见 `docs/ops/cleanup-release-runbook.md` 第 8 章。
