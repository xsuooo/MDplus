# 0.2.6 候选构建与验收

状态：**待原生验收，未发布**。当前正式下载仍为 0.2.5。本轮在 `codex/candidate-0.2.6` 准备后续候选；先前的质量修复 PR #3 已合并到 `release`。

## 构建改动

- npm、Cargo、Tauri 及锁文件的版本统一为 0.2.6。
- [KaTeX 构建处理](../../config/katexFonts.ts)仅处理 KaTeX CSS 的字体源，保留所有字体面的 family、style、weight、display 和原始 WOFF2 字节。缺失唯一 WOFF2 源时构建失败。
- [打包回归](../../tests/katexPackaging.test.ts)通过真实 Vite 构建核对 20 个字体面的属性、每份字体文件的字节，以及重复 WOFF/TTF 资源未进入产物。
- Rust release 使用 `opt-level = "s"`、ThinLTO、单个 codegen unit 和符号裁剪。保留默认 panic unwinding；启动和交互性能仍需通过真实安装版复核。
- 六份中文字体与其他字体文件均未改变。Cascadia 的无损 WOFF2 包装曾做独立评估：字体原始体积变小，但单文件 LZMA 近似值由 232,572 增至 237,924 字节，因此本轮保留 TTF。这是压缩估计，未计作实际 NSIS 收益。

## 实际 NSIS 对比

以下构建均使用 `candidate-0.2.6-size-study` 标记、相同锁定依赖和本机工具链。后面三个变体的输入文件哈希相同，仅 Rust 环境配置不同。每次构建均核对前后来源清单，直接测量 NSIS 及从包内提取的 `mdplus.exe`，未用 `dist/` 大小代替安装包大小。

| 变体                                  |  NSIS 字节 | NSIS MiB | 包内 EXE MiB |
| ------------------------------------- | ---------: | -------: | -----------: |
| 0.2.6 未优化基线                      | 49,362,100 |    47.08 |        54.34 |
| 仅 KaTeX WOFF2                        | 48,756,231 |    46.50 |        53.77 |
| KaTeX + ThinLTO，速度优化 `3`         | 48,718,133 |    46.46 |        53.22 |
| KaTeX + ThinLTO，体积优化 `s`（选用） | 48,266,124 |    46.03 |        50.75 |

选用变体较未优化基线少 **1,095,976 字节（1.05 MiB，2.22%）**，包内 EXE 少 3.60 MiB。六份完整中文字体自身合计 41.92 MiB，占主要体积；本轮保留字体覆盖和离线能力。EXE 大小不等于完整安装后磁盘占用，后者与冷启动时间均待原生环境测量。

本地证据目录为 `.audit/candidate-0.2.6-20261106/`，包含逐变体哈希、源码清单、构建日志、`size-comparison.json`、`font-integrity.json` 和 `cascadia-probe.json`。最终候选使用独立构建标记及单独哈希，不将研究变体的哈希当作最终候选。

## 已验证与限制

- 前端：480 项单测通过，lint、格式、配置同步、两套 TypeScript 及覆盖率门槛通过。
- 浏览器：179 项回归全部通过，使用真实 React/Milkdown/CSS/字体，原生 IPC 为模拟。
- Rust：格式与 Clippy 检查通过；最终 release 配置的测试结果随候选清单交付。
- 浏览器离线 HTML/PDF 样本单独标注来源，用于复核字体、公式、图表和长文内容；不代替 WebView2 原生 PDF 验收。

Windows 11 Sandbox 的原配置、禁用 vGPU 配置、未挂载任何项目目录的默认配置，均返回 `0x80370106`（虚拟机或容器意外退出）。Hyper-V 事件记录来宾 OS 启动后发起重置。失败发生在执行候选安装器前；目前尚未确定系统根因。没有将这些启动失败或旧版本的验收结果记作本候选通过。
