# 编辑工作流：替换、会话、图片与文稿导航

以下功能属于 v0.2.6 候选版，尚未发布。当前 README 下载链接仍指向 v0.2.5。2026-11-08 补充本地图片选择、源码目录和相对文稿链接，验证见[本轮修复记录](quality-fixes-2026-11-08.md)。

## 查找与替换

按 `Ctrl+F` 打开当前文稿的查找栏，点击左侧箭头展开替换行。可以替换当前匹配或全部匹配；替换内容留空会删除匹配文本。替换输入框中 `Enter` 执行单次替换，`Ctrl+Enter` 执行全部替换。大小写开关沿用查找设置，匹配使用普通文本规则。输入法组字期间不会执行替换或关闭搜索。

富文本模式查找可编辑的可见文本，包括普通代码块。替换保留标题、列表、代码、链接地址及相同的文字格式。一个匹配跨过不同格式或不同链接时会跳过，并显示「已替换／跳过」数量；Mermaid 与公式的隐藏源码通过源码模式编辑。

源码模式直接查找和替换 Markdown 原文，包括语法符号、链接地址和图表／公式源码。全部替换使用操作前的匹配集，插入的新文本不会在同一次操作中再次被替换。单次或全部替换均为一个撤销步骤，与前后输入隔开。

## 继续上次会话

「最近打开」菜单的「恢复上次会话」默认启用。下次启动会恢复已保存文稿的标签顺序、活动标签和阅读／编辑位置。每个文稿重新读取磁盘最新内容；位置使用短文本上下文定位，外部改动后会尽量跟随原位置。

双击文件或通过命令行指定文件时，仍恢复之前的文稿，同时优先显示本次指定的文件；同一路径复用现有标签。某个文件缺失或读取失败时，其余文稿继续恢复，失败集中显示并可重试。关闭提示后仍能从「最近打开」菜单重试。

正常关闭继续遵循保存、丢弃和取消确认。保存文稿的会话记录与异常退出后的草稿恢复分别保存，自动打开磁盘文件不会覆盖独立的待恢复草稿。未保存文稿通过原有草稿恢复入口找回；明确丢弃后不会自动回来。

## 插入本地图片

将 `.png`、`.jpg` 或 `.jpeg` 文件拖到富文本或源码正文中的插入位置，或点击工具栏「插入图片」多选本地文件。选择入口使用打开对话框前的选区末尾，保留选中文字；拖入使用鼠标落点。没有文稿时先新建或打开文稿。多张图片按文件名自然排序，例如 `1.png`、`2.png`、`10.png`，在同一位置整批插入；一个文件失败时保留其他成功文件，并汇总失败原因。整批图片可一次撤销和重做。

对话框打开或图片读取期间继续绑定原文稿和位置。期间的文字编辑会映射原位置；切换到另一标签后，可在原文稿中完成插入而不抢回焦点。关闭原文稿或改变原文稿的编辑模式会取消尚未完成的插入，包括切换模式后又切回原模式。取消选择不改变正文，选择器失败会明确提示并允许重试。

图片先复制到应用暂存。保存文稿时，将图片写到文稿旁的 `assets/` 并使用相对引用；未命名文稿在首次保存时迁移。原文件始终保留。当前不读取网络图片，可先下载后粘贴、拖入或选择本地图片。文件格式、大小与原生接口边界见 [IPC 契约](ipc.md)。

## 图片框选与查看

从正文空白处按住鼠标左键拖动，显示矩形选框；与矩形相交的图片显示半透明蒙版。可以向任意方向拖动，靠近编辑区上下边缘时自动滚动；按 `Ctrl` 或 `Shift` 框选可保留原来选中的图片。从文字开始拖动仍选择文字，从图片开始拖动仍可选择连续正文范围。

矩形选区只包含相交图片。复制、删除和粘贴替换不会带上夹在图片之间的正文或其他图片；删除可以撤销。`Esc` 取消当前框选并恢复原选区，切换标签或编辑模式也会取消尚未结束的框选。重新启动恢复会话时，多范围图片选区恢复为光标，避免把中间正文恢复成选区。

双击已加载的图片打开查看器，或使用图片上的「放大查看」按钮。查看器支持 `Ctrl+滚轮`、`Ctrl+=` / `Ctrl+-`，以及工具栏加减按钮；缩放保持鼠标下方或画布中心的图像位置。普通滚轮滚动图片，鼠标拖动画布可平移。手动缩放范围为 10%–400%，「适合窗口」仍可使用更小比例显示长图。

按 `Esc` 或关闭按钮返回编辑器，保留文稿选区与阅读位置。关闭动画保留最后显示的图片尺寸和位置，不修改文稿；系统开启减少动态效果时直接退出。

## 目录与相对文稿链接

富文本和源码模式均可打开目录。源码目录在停输后通过可取消的 Worker 解析当前 Markdown，识别 ATX 和 Setext 标题，不把围栏代码中的标题当作目录项。解析期间可继续输入，后续编辑或关闭目录会取消旧任务。点击标题定位当前 textarea 中的原文位置，并遵循系统减少动态效果设置；更新中和解析失败均显示文字反馈。

富文本链接普通点击继续编辑；`Ctrl+点击`，或把光标放在链接文字内按 `Ctrl+Enter`，打开相对 `.md`／`.markdown` 文稿。替换输入框中的 `Ctrl+Enter` 仍执行全部替换，两者按焦点区分。链接以来源文稿当前保存目录解析，另存为后使用新目录；已有同路径标签直接复用，不重读并覆盖未保存内容。

来源尚未保存时提示先保存，目标不存在时显示打开失败，不创建文件。含 `#标题` 的文稿链接会打开文件并提示尚未定位标题；源码中的链接导航、跨文稿标题定位、绝对路径、其他协议和查询参数暂不支持。

## 保存与操作提示

新建文稿先通过工具栏保存并选择位置，之后才自动保存。工具栏、标签新增按钮和状态栏使用当前生效的快捷键提示；解绑保存键后，提示指向工具栏保存。欢迎页最近文稿显示父目录，并可通过完整路径区分同名文件。最近列表读写失败会反馈，文稿保存成功与最近列表更新失败分别说明。

## 验证入口

`npm run check` 覆盖前端格式、静态检查、两套 TypeScript、单测与覆盖率门槛。统一浏览器回归的 `-Cases all` 包含替换、会话恢复、图片插入和导航／提示用例，使用真实 React/Milkdown 与浏览器布局，只模拟原生文件／窗口接口。

原生图片导入另有真实 PNG/JPEG 解码、损坏／超限文件拒绝、不可变副本和原文件保留测试。发布前仍按 [开发与质量检查](development-quality.md) 执行 Windows 原生与安装验收，浏览器的模拟事件不能替代系统文件拖放、输入法和 DPI 验收。

### 搜索栏外观调整

搜索栏采用中性边框与轻阴影，关键词输入区包含按钮式 Aa 开关；匹配导航成组，展开的替换行突出「全部替换」。窄窗口中匹配导航与替换操作换行，保留完整的输入区。Aa 仍使用原生复选框，可通过 Tab 和空格操作。

外观调整后，10 项搜索／替换单测和 16 项相关浏览器回归通过。真实 SearchBar 的浅深主题、展开／收起、匹配／无匹配及长结果提示在 280、310、320、390、800、1280px 宽度的 72 项布局检查中通过，12 项 Aa 键盘检查通过；生产前端与 Windows 测试程序重新构建成功。更新后的测试程序沿用原试用配置，实际启动恢复了此前的两份文稿及活动标签。
