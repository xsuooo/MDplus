# MDPlus 功能审计

审计时间：2026-11-08 23:23 至 2026-11-09，本地时间 UTC+08:00。最后一次写报告前的基线核验为 2026-11-09 00:54。

## 1. 结论和判定口径

**当前项目不是只有 [README](README.md) 中列出的几个按钮。它已经是一套 Windows Markdown 编辑器，另有文件安全、恢复、会话、图片所有权、离线导出和交付工具。** 主要问题不是缺少基础功能，而是工作树新增功能尚未提交、部分测试没有跟上新行为，以及两处已复现的 Markdown/选区错误。

- 审计对象是当前工作树，不是纯 HEAD，也不是下载页面的安装包。分支为 `codex/candidate-0.2.6`；HEAD 为 [`8b9d984`](https://github.com/xsuooo/MDplus/commit/8b9d984)。
- 当前代码版本为 0.2.6 候选版。[README](README.md#L7-L35) 的公开下载仍指向 v0.2.5。不能把本报告里的未提交功能归到 v0.2.5 安装包。
- 起始工作区已有 99 个修改的跟踪文件、107 个未跟踪文件，共 206 行 Git 状态。372 个跟踪或非忽略的审计输入文件已复制到仓库外；原来的修改全部保留。
- 阅读覆盖包括全部 98 个前端 TS/TSX/CSS 文件、全部 Rust 生产模块、IPC/权限/配置、安装模板、脚本、CI、相关测试和维护文档。枚举了本地全部 60 个可达 commit，并核对初始内容及主要功能引入/删除 patch。没有 fetch 或查询远端最新 CI。
- 不把每个类型、图标、样式声明或第三方库导出都伪装成独立功能。下表按用户行为、底层能力和维护入口列条目。前后端分层、不同生命周期和不同安全边界，不算重复实现。

## 2. 哪些是核心，哪些可以删

### 核心功能，建议保留

1. **文稿编辑闭环**：富文本/源码、CommonMark/GFM、两种撤销历史、原文保全。模式切换可用，但结构化选区往返有已确认缺陷。
2. **文件和数据保护**：打开、首次保存、自动保存、另存为、字节版本 CAS、冲突副本、关闭确认和崩溃恢复。这些比外观功能更重要。
3. **多文稿工作流**：标签隔离、最近文件、会话恢复、目录、查找替换和相对文稿链接。
4. **Markdown 内容能力**：本地图片及其保存/恢复/撤销生命周期、代码高亮、任务列表、KaTeX、Mermaid 和媒体查看。
5. **桌面和交付基础**：窗口/偏好持久化、单实例、离线 HTML、明确 IPC 权限、配置一致性及安全交付守卫。PDF 是系统打印流程，不是直接生成并确认落盘的 API。
